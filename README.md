# avito-bicycle-demo
Учебная модель API для практики автоматизированного сбора данных в CodeChef: объявления сети веломагазинов в трёх городах, по 100 вымышленных записей на город. JSON и HTML-документация для размещения на статическом хостинге без серверного кода. Не является официальным API Авито.
